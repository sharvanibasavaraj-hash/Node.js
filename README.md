This repository contains my Node.js learning programs and a practical project developed while learning backend development.

1. Basic Node.js Operations

7. File Reading and Appending

9. JSON Handling
10. Basic HTTP Server

## Learning Project – Student Record Manager

A command-line application developed using Node.js.

**Features:**
- Add student records
- View all students
- Search students by ID
- Update student details
- Delete student records
- Store records using JSON files

## Technologies Used

- JavaScript
- Node.js
- npm
- Built-in Node.js Modules
- File System
- JSON
- HTTP Module

## How to Run

Install Node.js, clone the repository, and run the required program:

```bash
node filename.js
```

To run the Student Record Manager:

```bash
node student-manager.js
```

## Purpose

To understand Node.js fundamentals and gain practical experience with server-side JavaScript before learning Express.js.
